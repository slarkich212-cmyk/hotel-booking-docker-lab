# Лабораторная работа: Контейнеризация приложения бронирования отелей

**Тема:** Бронирование отелей  
**Задание:** Развернуть многокомпонентное приложение (фронт, бэк, БД) с помощью Docker Compose.

## Описание

Веб-сервис для управления **Журналом бронирований номеров**.

Функционал:
- Просмотр списка всех бронирований из базы данных.
- Расчет стоимости проживания по датам заезда и выезда.

## Архитектура

Приложение состоит из трех контейнеров:

1. **Frontend** — HTML-страница с кнопками, раздается через Nginx.
2. **Backend** — REST API на Python (Flask), обрабатывает запросы и делает расчеты.
3. **Database** — PostgreSQL, хранит таблицу `reservations`.
